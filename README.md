# 🛒 Retail Sales ETL & Power BI Analytics

## 📌 Project Overview

This project demonstrates an end-to-end **ETL (Extract, Transform, Load) and Business Intelligence workflow** using a retail transaction dataset.

The project starts with raw Excel data containing data-quality issues and inconsistencies. The data was cleaned and transformed using **Excel Power Query** and then loaded into **Power BI** to create an interactive sales analytics report.

The objective was to transform raw transactional data into a clean, reliable, analysis-ready dataset and use Power BI to generate meaningful business insights.

---

## 🎯 Business Objective

The project focuses on analyzing retail transaction data to understand:

- Overall sales performance
- Product category performance
- Customer purchasing activity
- Geographic sales distribution
- Payment method preferences
- Order status distribution
- Cancellation and return behavior
- Sales and transaction trends
- Data-quality issues in the source dataset
